# mono-film
MONO FILM 是一款以韓系灰白極簡風格為設計核心的互動式四格拍貼 Web App，旨在將傳統實體拍貼機的操作體驗延伸至線上平台。使用者可透過即時相機拍攝或上傳照片，自由選擇拍貼版型、濾鏡、相框與裝飾，打造個人化的拍貼作品。

除了基本的照片編輯功能，網站更結合沉浸式攝影棚、創意姿勢導演、神祕盲盒挑戰、情緒主題相框、鏡像特效及 Living Film 動態拍貼，提升使用者的參與感與趣味性。完成後還能下載拍貼、產生專屬回憶收據，並將作品收藏至私人底片牆。

本作品透過 Vibe Coding 開發，使用 HTML、CSS 與 JavaScript 實作，無須安裝額外軟體或註冊帳號，即可透過瀏覽器體驗，讓拍貼不只是照片製作，更是一段充滿創意與驚喜的回憶旅程。
